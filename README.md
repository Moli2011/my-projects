## Локальный запуск

Просто откройте [index.html](index.html) в браузере, либо запустите локальный сервер:

```bash
npx serve .
```

## Управление

| Клавиша | Действие |
| --- | --- |
| ← / → | Движение влево/вправо |
| ↓ | Ускоренное падение |
| ↑ | Поворот фигуры |
| Space | Мгновенный сброс |
| C | Удержать фигуру |
| P | Пауза |

На мобильных устройствах доступны экранные кнопки управления.
